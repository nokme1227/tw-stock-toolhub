方法與限制

散戶定義：集保股權分散表 1–8 級（50 張以下）。變化率＝（本週人數−上週人數）÷上週人數。
過濾：上週基數 <1,000 人不列入；單週變化率超出 −90%～+500% 視為來源異常剔除。
數據：TDCC 集保每週快照（經 GitHub 鏡像），每週六更新。本頁無即時抓取，開啟不消耗 API 額度。
⚠️ 僅供籌碼研究參考，不構成投資建議；散戶增減與股價無必然因果。
